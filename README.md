## 🚀 ABOUT THE PROJECT

</div>

Celestial Bodies Database is a PostgreSQL project designed to organize information about galaxies, stars, planets, and moons.

The project demonstrates relational database design, data relationships, SQL commands, and database constraints.

<div align="center">

## 🪐 DATABASE STRUCTURE

| Table | Description |
|:---:|:---|
| 🌌 `galaxy` | Stores galaxy information |
| ⭐ `star` | Stores stars and their galaxy relationships |
| 🪐 `planet` | Stores planets and their star relationships |
| 🌙 `moon` | Stores moons and their planet relationships |
| 🔭 `planet_types` | Stores different planet categories |

## 📊 DATABASE STATISTICS

| Database Component | Records |

</div>
